<p align="center">
  <h1 align="center">Kiroku</h1>
  <p align="center">a minimal TUI task manager with spaces, two-column layout, and local persistence.</p>
</p>

## Install

```bash
brew install kenanbendz/tap/kiroku
```

Or manually:

```bash
brew tap kenanbendz/tap
brew install kiroku
```

Then just run:

```bash
kiroku
```
